# Welcome to the Mow No Mo Schedule and Client application
This application handles all the scheduling and client data for the best mowing company in NoVA, Mow No Mo!

## Pages:
- Home (Schedule)
- Add a Client

## Deployment:
To deploy changes, add/commit/push changes to feature branch, then merge with main via pull request.
Then, from main branch, run these commands:
```
npm run build
npm run deploy
```
